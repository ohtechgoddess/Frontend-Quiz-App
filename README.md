# Frontend Quiz App

A simple frontend quiz application built with HTML, CSS, and JavaScript to practice core frontend concepts.

## Features
- Name-based login using localStorage,
- Clean, responsive UI,
- HTML and CSS quizzes,
- Score tracking with encouragement messages,
- Portfolio starter template.

## Tech Stack
- HTML,
- CSS,
- JavaScript

## Purpose
This project focuses on frontend fundamentals, honest scoping, and clean UI without using a backend.
